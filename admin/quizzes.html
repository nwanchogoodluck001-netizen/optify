Quiz Security

Important implementation requirements

Quiz questions, correct answers, attempt limits and rewards must be controlled by the backend.

Correct answers should never be exposed through production frontend code.

Reward calculations and balance updates must be performed and verified server-side.

Admin actions should be authenticated, authorized and recorded in audit logs.
